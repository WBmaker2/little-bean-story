# 🌱 강낭콩의 사계 (Little Bean Story)

> **"씨앗에서 피어나는 생명의 경이로움, 손끝으로 느끼는 자연주의 인터랙티브 교육 웹앱"**

학생들이 식물의 일대기를 감각적이고 직관적으로 체험할 수 있도록 제작된 반응형 인터랙티브 웹 애플리케이션입니다.  
수채화 물감의 따뜻한 번짐과 거친 종이 질감 속에서 **씨앗 심기 → 발아 → 줄기 성장 → 개화 및 정원 일기 쓰기**까지의 4단계를 단계별로 탐구할 수 있습니다.

## ✨ 주요 기능 및 단계별 체험 시나리오

| 단계 | 테마 | 핵심 인터랙션 & 피드백 |
|:---:|:---:|:---|
| **1단계** | **씨앗 심기** | • 씨앗 바구니의 **강낭콩 씨앗**을 드래그하여 중앙의 **포근한 흙** 위로 이동<br>• 마우스 드롭 및 모바일 터치 드래그, 클릭 지원<br>• 흙 속에 쏙 파묻히며 흙먼지가 이는 애니메이션<br>• 메시지: *“씨앗이 포근한 흙 속에서 잠들었어요.”* |
| **2단계** | **물 주기와 발아** | • **‘물 주기’** 버튼 클릭 시 촉촉한 물방울 낙하 및 수채화 링 파동 효과<br>• 3번의 물주기를 완료하면 떡잎과 어린 줄기가 기지개를 켜며 쏙 솟아남<br>• 메시지: *“와! 소중한 첫 싹이 기지개를 켜며 깨어났어요.”* |
| **3단계** | **햇살과 줄기 성장** | • 상단에 회전하는 **‘황금빛 해님’**을 마우스/터치로 좌우 이동<br>• 해님 위치를 추적하여 줄기가 부드러운 곡선(Bézier Curve)으로 굴광성(向光性) 반응<br>• 줄기 내부에 **소프트 민트색 물길(빛나는 수액 흐름)**이 반짝이며 순환<br>• 메시지: *“햇살을 듬뿍 받은 줄기가 하늘을 향해 쑥쑥 자라요.”* |
| **4단계** | **개화와 일기 쓰기** | • 화사한 분홍빛 꽃송이 개화 및 통통한 강낭콩 꼬투리 결실<br>• 정원 주위를 맴도는 나비와 축하 꽃가루 파티클 연출<br>• **오늘의 정원 일기**에 이름과 느낀 점을 입력하면 우아한 손글씨 편지지에 영구 기록<br>• 메시지: *“세상에서 가장 아름다운 꽃이 피었습니다!”* |

## 🎨 디자인 철학 및 가이드라인

- **톤 & 무드:** 생명력, 치유, 자연주의, 부드럽고 따뜻함
- **색상 팔레트:**
  - `배경색`: `#F0F4EC` (연한 세이지 그린)
  - `텍스트`: `#2C4A1E` (딥 포레스트 그린)
  - `강조색 1`: `#E8C4A0` (따뜻한 베이지)
  - `강조색 2`: `#C9E0C0` (소프트 민트)
  - `꽃/해님`: `#F8B4C4` (소프트 핑크), `#F4A836` (골드 옐로우)
- **수채화 텍스처 & 아트워크:**
  - 외부 이미지 링크 없이 **순수 CSS와 SVG `<filter>`**(`feTurbulence`, `feDisplacementMap`, `feGaussianBlur`)로 물감이 종이에 번지는 아날로그 감성을 100% 코드로 구현
  - 브라우저 전면 거친 종이 질감(Paper texture) 오버레이 적용
- **타이포그래피:**
  - 제목 및 상태 메시지: 우아한 명조 계열 `Gowun Batang`, `Nanum Myeongjo`
  - 일기장 손글씨: 아기자기한 감성의 `Nanum Pen Script`

## 🛠 기술 스택

- **Frontend:** Vanilla HTML5, CSS3, Modern JavaScript (ES6+)
- **Graphics & FX:** Inline SVG, SVG Filter Primitives, CSS Keyframe Animations
- **Hosting / CI:** GitHub Pages
- **Optimization:** 외부 이미지 의존성 0%, 가벼운 단일 번들 구조, 60fps 부드러운 인터랙션

## 💻 로컬 실행 방법

별도의 복잡한 설치 없이 브라우저에서 바로 실행할 수 있습니다.

```bash
# 저장소 복제
git clone https://github.com/WBmaker2/little-bean-story.git

# 폴더 이동
cd little-bean-story

# 로컬 웹 서버 실행 (Python 3 기준)
python -m http.server 8080
```
브라우저 주소창에 `http://localhost:8080`을 입력하여 접속합니다.

## 🌿 교육적 활용 팁 (초·중등 과학/원예)
1. **씨앗의 조건:** 발아에 필요한 수분, 온도, 공기의 중요성 관찰
2. **굴광성 탐구:** 빛을 향해 줄기와 잎이 자라나는 식물의 특성을 직접 해님을 조작하며 체득
3. **관찰 일지 작성:** 식물이 자라는 과정을 언어화하고 생명의 소중함을 기록
